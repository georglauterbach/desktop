# GTK3

GTK3 apps get the same look and theme name from a custom-built, patched version of [adw-gtk3](https://github.com/lassekongo83/adw-gtk3), a GTK3 port of libadwaita. GTK3 ignores the system color scheme, so [`theme`](../../.local/bin/theme) selects the dark variant through `gtk-application-prefer-dark-theme`, which makes GTK3 load `gtk-dark.css` instead of `gtk.css`.
