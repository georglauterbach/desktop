# GTK4

GTK4 libadwaita apps ignore `gtk-theme-name` and draw from the stylesheet compiled into the library. Since libadwaita is bundled, only the bundled programs from the container that use libadwaita load it. A process can only load one glibc and one GTK, so host apps keep loading the host's stock libadwaita. They, and Flatpak apps, are recolored by [`data/home/.config/gtk-4.0/gtk.css`](gtk.css) instead, which follows the system color scheme and requires GTK 4.20 or newer.

GTK4 apps that do not use libadwaita fall back to GTK's built-in Adwaita, which the stylesheets cannot recolor. They need the patched stylesheet as a theme directory instead, which the container builds as `Evergruv`, too. It requires GTK 4.23.1 or newer.
